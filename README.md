# 🚗 SmartPark - ჭკვიანი პარკინგის მართვისა და მონიტორინგის სისტემა

თანამედროვე, რეალურ დროში მომუშავე ჭკვიანი პარკინგის მართვის, მონიტორინგისა და დაჯავშნის სისტემა.

---

## ✨ ძირითადი ფუნქციონალი (Key Features)

- 🅿️ **ინტერაქტიული პარკინგის რუკა**: თავისუფალი და დაკავებული ადგილების რეალურ დროში მონიტორინგი.
- 💰 **დინამიური ტარიფების მართვა ადმინ პანელიდან**:
  - საბაზისო საათობრივი ტარიფის რედაქტირება (მაგ. 1 სთ = 1 ₾).
  - შეღავათიანი პაკეტის საათებისა და ფასის კორექტირება (მაგ. 2, 3, 4, 5, 6 საათიანი პაკეტები).
  - დღიური (24 სთ) ტარიფისა და საათების რედაქტირება (მაგ. 24 სთ = 5 ₾).
  - ტარიფების ავტომატური სინქრონიზაცია მთელ სისტემაში (რუკა, თანამშრომლის ტერმინალი, შლაგბაუმის სიმულატორი, ჯავშნები).
- 🔒 **იზოლირებული ადმინ პანელი**:
  - დაცულია ადმინისტრატორის პაროლით.
  - თანამშრომლისა და მძღოლის ანგარიშებიდან ადმინ პანელში შეღწევის მკაცრი შეზღუდვა.
  - შემოსავლების ანალიტიკა, სტატისტიკა და ისტორია.
- 🚧 **შლაგბაუმის სიმულატორი (ANPR / LPR)**:
  - ნომრის ამოცნობის კამერა (ავტომატური გაღება თანამშრომლებისთვის და აქტიური საშვებისთვის).
  - ბარკოდისა და QR კოდის სკანერი.
- 🎫 **თანამშრომლის ტერმინალი (Staff Terminal)**:
  - სწრაფი გატარება, ქვითრის ბეჭდვა, გადახდის დაფიქსირება.
- 👥 **მძღოლებისა და თანამშრომლების ბაზა**:
  - თანამშრომელთა ნომრების დაშვების სია (Whitelist).
  - გადამხდელი კლიენტების ისტორია და აქტიური ბილეთები.
- 🌐 **ორენოვანი მხარდაჭერა**: ქართული და ინგლისური ენები.

---

## 🚀 ტექნოლოგიური სტეკი (Tech Stack)

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, Motion.
- **Backend**: Node.js, Express, TSX.
- **State & Sync**: Custom Event Dispatcher, LocalStorage Sync & REST API.

## 💻 ლოკალურად გაშვება (Getting Started)

### 1. რეპოზიტორიის კლონირება
```bash
git clone https://github.com/<შენი-იუზერი>/smartpark.git
cd smartpark
```

### 2. დამოკიდებულებების ინსტალაცია
```bash
npm install
```

### 3. აპლიკაციის გაშვება დეველოპმენტ რეჟიმში
```bash
npm run dev
```
აპლიკაცია გაეშვება მისამართზე: `http://localhost:3000`

### 4. საპროდაქშენო ბილდი
```bash
npm run build
npm start
```
